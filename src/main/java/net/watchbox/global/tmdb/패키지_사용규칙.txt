0. 개요
tmdb 패키지는 TMDB API에 요청하여 데이터를 응답 받고 가공하는 역할을 한다.
가공이란 TMDB API 응답을 WatchBox 서비스에 맞게 변환하는 것을 의미한다.
패키지 구조와 네이밍은 TMDB API Reference 페이지의 카테고리와 네이밍대로 1:1 매핑한다.

1. 패키지 용도
1) service 패키지
Tmdb{$CATEGORY}Service.class
$CATEGORY - TMDB API Reference 페이지 좌측 메뉴에 표기된 카테고리명 (ex: MOVIES, MOVIE LISTS, ACCOUNT..)
한 카테고리의 여러 메뉴 요청이 클래스에 들어 있다

2) response 패키지
../{$CATEGORY}/Tmdb{$CATEGORY}{$MENU}Response.class
카테고리명 + 메뉴명
$MENU - TMDB API Reference 페이지 좌측 메뉴에 표기된 메뉴명 (ex: Details, TV Details, Person Details..)
'Common' - 여러 항목에 공통으로 사용되는 경우 $MENU 대신 사용
해당 패키지의 클래스는 TMDB API 응답을 그대로(1차로) 매핑하는 용도로 사용된다.

3) inner 패키지
Tmdb{$KEY}Item.class
$KEY - TMDB API 응답으로 받는 JSON 객체의 key 관련 네이밍
하나의 Item 클래스가 여러 Response 클래스에서 재활용 되는 경우도 많기에 따로 분리하여 inner 패키지에 두었다.

4) util 패키지
주로 Tmdb 응답을 가공하는데 필요한 유틸리티 클래스들
